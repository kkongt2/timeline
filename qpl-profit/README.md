# 복연승 · 같은 금액, 누적 수익

기존 `kkongt2/timeline` 페이지에서 분리하여 별도 저장소에 배포하도록 만든 복연승 전용 정적 웹 앱입니다. 자동 사전예측 기록, 연승 추천, 적중률/가치 기준 전환은 포함하지 않습니다.

## 현재 결과

공식 보고서 1,620개, 경주 이력 12,903건 중 복연승 확정 배당을 확인한 12,714경주를 확보했습니다. 2021년은 과거 이력 생성에 사용하고, 이후 11,092경주의 552,415개 조합으로 모델을 구성했습니다.

| 구간 | 역할 | 경주 수 |
|---|---|---:|
| 2022–2024 | 확률 및 적중 시 배당 모델 학습 | 7,031 |
| 2025.01–03 | 확률·배당 보정 | 586 |
| 2025.04–12 | 총 순손익으로 조건 선택 | 1,806 |
| 2026.01–09.10 | 선택 조건 고정 후 평가 | 1,669 |

배당 모델 2종 × 기대수익률 하한 8종 × 경주당 최대 조합 수 3종, 총 48개 조건을 비교했습니다. 선택 구간에서 가장 높은 총 순손익을 보인 연구 조건은 **Gamma 배당 모델, 기대수익률 10% 이상, 경주당 상위 1조합**입니다. ROI가 아니라 같은 단위 금액을 베팅한 **총 순손익**으로 선택했습니다.

| 결과 | 조건 선택 구간 | 분리 평가 구간 |
|---|---:|---:|
| 조합 수 | 447 | 426 |
| 고정 단위금액 | 1,000원 | 1,000원 |
| 총 베팅액 | 447,000원 | 426,000원 |
| 세전 순손익 | -48,900원 | +26,100원 |
| 수익률 | -10.94% | +6.13% |

평가 구간 적중률 15.73%, 적중 시 평균 배당 6.75배, 일별 최대 낙폭 56,100원. 수익률의 날짜 단위 재표집 95% 신뢰구간은 **-27.11% ~ +40.24%**입니다. 최고 수익일을 제외하면 **-12,600원**입니다.

**흑자 검증 통과 실패. 현재 실행 정책은 베팅 추천 보류입니다.** 선택 구간에서 손실이 났으므로 아무것도 베팅하지 않는 선택(손익 0)이 더 좋습니다. 화면의 조합은 비교를 위한 연구 후보이며, 장기 흑자 전략으로 승인된 추천이 아닙니다. 2026년 결과를 보고 추가 조정하지 않았습니다.

## 하나의 추천 기준

`추정 기대수익률 = 추정 적중확률 × 적중 시 예상 환급배당 − 1`

- 적중확률: 과거 경주 이력으로 학습한 이진 분류 모델과 별도 보정.
- 예상 배당: 과거 적중 조합의 확정 배당으로 학습한 조건부 평균 배당 모델. 실시간 배당이나 미래의 실제 배당을 입력하지 않습니다.
- 경주당 허용 조합 수까지 기대수익 순으로 선택하고, 각 조합에 같은 1,000원을 적용합니다. 복리·추격 증액을 사용하지 않습니다.
- 공식 배당으로 환급액을 계산한 뒤 베팅 원금을 차감합니다. 공식 배당에 반영된 공제율을 다시 빼지 않습니다. 개인별 적중금 세금·입장 비용은 반영하지 않은 **세전** 손익입니다.
- `1 / 추정 적중확률`은 세전 손익분기 배당입니다. 사용자의 실제 적용 배당과 모델 추정 배당은 다를 수 있습니다.

승인 조건은 선택 구간 흑자, 분리 평가 200조합·60경기일 이상, 수익률 95% 신뢰구간 하한 0 초과, 최고 수익일 제외 후에도 흑자입니다. 기준에 실패하면 연구 후보만 보여줍니다. 48개 후보 밖의 전역 최적값이나 미래 흑자를 입증한 것은 아닙니다.

## 별도 저장소 배포

1. 빈 공개 GitHub 저장소를 만듭니다. 제안 이름: `qpl-profit`.
2. **이 디렉터리의 내용**을 새 저장소 `main` 브랜치 루트에 올립니다.
3. 새 저장소의 **Settings → Pages → Source → GitHub Actions**를 선택합니다.
4. `Update and publish QPL page` 작업을 실행합니다. 성공 시 작업 결과에 새 페이지 주소가 나옵니다.

워크플로는 자신의 저장소에만 데이터 갱신 내용을 저장하고 Pages를 직접 배포합니다. 기존 `timeline` URL이나 브랜치를 참조하지 않습니다. 목~일 한국시간 09–21시에는 약 20분마다, 월~수에는 09:05에 실행하도록 설정했습니다. GitHub 예약 실행은 지연될 수 있습니다. 수집 실패 시 마지막 게시 파일을 유지하며, 화면은 데이터가 30분보다 오래되면 갱신 필요를 표시합니다.

기존 자동 사전예측 저장·정산 작업은 복사하지 않았습니다. `backtest-bets.json`은 모델 검증용 과거 계산 자료로, 사용자의 실제 베팅이나 실제 사전예측 기록이 아닙니다.

## 로컬 실행과 검증

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

```sh
pip install -r requirements.txt
node tests/model.cjs
node tests/ui.cjs
python -m unittest discover -s tests -p 'test_*.py'
```

Python–JavaScript 수치 일치, 말 순서 변경, 결측·오래된 이력, 출전 두수 변경, 실제 배당과 고정금액 손익 일치, 승인 조건, 원클릭 라운드 선택, 지역별 경주일, 과거 확정 결과 표시를 검사합니다.

재현:

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python scripts/train_profit.py
```

학습 데이터와 배당 라벨은 저장소에 포함되어 있습니다. `Reproduce frozen profit experiment` 작업도 같은 실험을 재현하지만 결과를 자동 배포하거나 모델을 교체하지 않습니다. 새로운 가설을 검증할 때는 이 평가 결과를 본 사실을 기록하고, 다른 미사용 기간으로 평가해야 합니다.

## 데이터와 한계

- 한국마사회 공식 일별 결과 보고서: `training/manifest.json`에 원본 URL과 해시.
- 검증된 조합별 확정 배당: `training/payouts.json.gz`에 보고서 URL·원문 해시.
- 배당 미확인·해석 제외 189경주: `training/payout-quality.json`. 누락 배당은 0배나 미적중으로 대체하지 않습니다.
- 날짜마다 같은 날 결과를 입력하기 전 모든 경주의 특징을 생성합니다. 개별 말 현재 경주의 착순·구간 기록·배당은 사전 특징에 포함하지 않습니다.
- 역사적 보고서에 영구 말 ID가 없어 지역·이름·출생연도 추정·성별을 조합합니다. 이름 변경 등으로 이력이 분리될 수 있습니다.
- 2026년 구간은 이번 수익 실험에서만 선택과 분리했습니다. 이전 적중률 연구에서 사용된 날짜이므로 완전히 새로운 독립 시험이 아닙니다.
- 최대 낙폭은 경기일 종료 누적 손익 기준이며 장중 낙폭을 뜻하지 않습니다. 같은 경주의 여러 조합은 서로 독립적이지 않습니다.
- 현재 모델은 2024년까지 학습한 고정 모델입니다. 사전 이력 입력은 갱신하지만 새 결과로 자동 재학습하지 않습니다.

학습·조건·평가 근거는 `data/experiment.json`, `data/frozen-policy.json`, `data/backtest.json`에 남아 있습니다.
